## 🗺️ 未来三年规划：走就业路线

我选择**就业**作为主线。理由很直接：我喜欢"做出能被别人用的东西"这个过程，也想尽早进入真实工程环境，用真实项目的复杂度倒逼自己成长；同时我的算法与底层基础目前偏弱，直接冲考研的风险和收益不成正比。这不是放弃深造，而是先把工程能力扎稳——读研可以是在职的事，工程手感只能靠项目堆出来。

| 阶段 | 重心 | 具体目标 |
| :--- | :--- | :--- |
| **第 1 年**<br>打地基 | 基础 + 手感 | ① 数据结构与算法：LeetCode 200+ 题，覆盖数组/链表/树/图/DP；<br>② 数据库：学完原理，能独立设计含索引与事务的业务表；<br>③ Git 协作：用分支 + PR + Review 完整参与一个多人项目；<br>④ 期末代码量达到 **15,000 行**，且带单元测试 |
| **第 2 年**<br>做深度 | 项目 + 实习 | ① 完整交付 2 个可写进简历的项目（后端/数据方向，有文档、有部署、有真实用户量哪怕很小）；<br>② 深耕一门主语言（Python 或 Java）到"能读懂开源项目源码"的程度；<br>③ 拿到第一份**暑期实习**，体验真实研发流程（需求评审 → 开发 → 联调 → 上线） |
| **第 3 年**<br>收成果 | 秋招 + 沉淀 | ① 秋招前完成 3 轮系统性复盘（算法、项目、八股）；<br>② 拿到与方向匹配的 **校招 offer**；<br>③ 毕业设计做一件自己真正想做的事，而不是"为了毕业而做"<br>④ 累计代码量目标 **50,000 行** |

## 🎯 兴趣爱好 & 想分享的一段经历

- 🏋️ **健身**：和写代码很像——没有捷径，只有周期、复现和耐心。连续三年每周三次，教会我"长期主义"不是口号而是日程表。
- 📷 **摄影**：这直接影响了我在 AI 图像作业里的判断标准。我能一眼看出一张生成图"假"在哪——皮肤没有毛孔、光线方向不一致、背景虚化不符合光学规律。这让我在调提示词时知道该加什么：`85mm f/1.4`、`shallow depth of field`、`natural skin texture`。
- 🧰 **折腾工具**：从截图水印脚本到自动排版工具，我享受"把一个动作重复三次 → 就把它写成脚本"的过程。

**印象最深的一次踩坑**：在做 AI 图像作业时，本机无法直连 Hugging Face，平台上的 Flux 模型又恰好下架。我没有停在"环境不支持"，而是排查了代理、镜像、替代平台的可用性，最后换用同源模型完成端到端验证，并在报告里如实写清了切换原因。**那次我学到：工程师的价值不在于"环境完美时能跑通"，而在于"环境不完美时还能交付"。**
